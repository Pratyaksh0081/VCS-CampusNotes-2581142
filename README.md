# CampusNotes

CampusNotes is a browser-based study notes manager that helps students organize their study notes. It is built using HTML, CSS and JavaScript.

## Features

- Add new notes with a subject and description.
- Display saved notes.
- Search notes by subject or content.
- Delete notes when they are no longer needed.
- Save notes using browser localStorage.

## Project Files

| File | Description |
|---|---|
| `index.html` | Main application page |
| `style.css` | Application styling |
| `script.js` | Handles adding, displaying, searching and deleting notes |
| `README.md` | Project documentation |
| `.gitignore` | Specifies files Git should ignore |

## How to Run

Requirements: Git and a modern web browser.

1. Clone the repository:

   `git clone https://github.com/Pratyaksh0081/VCS-CampusNotes-2581142.git`

2. Open the project folder:

   `cd VCS-CampusNotes-2581142`

3. Open `index.html` using Live Server or directly in your browser.
4. Start adding and managing your study notes.

## Data Storage

The application uses browser localStorage to save notes. Saved notes remain available in the same browser unless its stored site data is cleared.
