# VCS-CampusNotes-2581142

CampusNotes project for VCS Assignment 2.

## About
CampusNotes is a simple front-end project built with HTML, CSS and JavaScript. It is used in this course to practise Git and GitHub collaboration (forks, pull requests and code review).

## Project files
- `index.html` - main page of the application
- `style.css` - styling
- `script.js` - application logic

## How to run
1. Clone the repository: `git clone https://github.com/Pratyaksh0081/VCS-CampusNotes-2581142.git`
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.
