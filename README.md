# VCS-CampusNotes-2581142

## About
CampusNotes is a browser-based study notes manager that lets students add, search, view, and delete notes. It is a simple front-end project built with HTML, CSS and JavaScript, and it is used in this course to practise Git and GitHub collaboration (forks, pull requests and code review).

## Features
- Add new study notes
- Display saved notes
- Search notes
- Delete notes

## Project files
- `index.html` - main page of the application
- `style.css` - styling
- `script.js` - application logic: adding, displaying, searching and deleting notes

## How to run
Requirements: Git and a modern web browser (for example Chrome, Edge or Firefox).
1. Clone the repository: `git clone https://github.com/Pratyaksh0081/VCS-CampusNotes-2581142.git`
2. Open the project folder: `cd VCS-CampusNotes-2581142`
3. Open `index.html` in your browser by double-clicking it, or run `start index.html` on Windows or `open index.html` on macOS.

## Contributing notes
1. Fork the repository and create a branch, for example `feature/<your-name>-add-notes`.
2. Add or edit your notes in the project.
3. Commit your changes with a clear message and push the branch.
4. Open a pull request describing what you added and why.
